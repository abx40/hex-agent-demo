# Play against my Hex agent

[Play the 11×11 Hex demo](https://abx40.github.io/hex-agent-demo/).

The COMP34111 Group 13 agent runs locally in your browser with ONNX Runtime Web. Choose who starts, then select **Start**. Red opens and connects top to bottom. Blue connects left to right and can swap colours on turn two.

See [local play instructions](README.txt) and [HexHex model credits and license information](notices/MODEL-SOURCE.md).
